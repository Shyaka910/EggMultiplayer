Overview

A multiplayer co-op third-person shooter inspired by survival gameplay systems. Built in Unreal Engine 5 with full server-authoritative replication, AI-driven infected enemies, and Steam online multiplayer integration.

Core Features

  • Full Multiplayer Replication (Server-authoritative architecture)
  • Weapons system (hitscan + projectile weapons)
  • Grenades with replicated physics simulation
  • Pickup system (ammo, weapons, health potions)
  • Smart AI infected using Behavior Trees
  • NavMesh-driven navigation system
  • Replicated doors and world interactions
  • Match scoreboard system
  • Steam Online Sessions (lobby + matchmaking)

Technical Breakdown

  • Unreal Engine 5.7 (C++)
  • Actor + Component replication system
  • RPC-based gameplay communication
  • AI Behavior Trees & Perception system
  • Physics replication for interactive objects
  • Dedicated server-ready architecture

Architecture

Server-authoritative design:

Server: Handles gameplay logic, AI, damage, scoring
Clients: Send input requests and receive replicated state
Replication: Movement, combat, pickups, and interactions
